Initial release. Look up and validate companies by name in national business registries: adapters for Israel, Norway, Finland, France, Czechia, the United Kingdom, Australia, New Zealand, Switzerland and OpenCorporates (US, Canada, Poland), a GLEIF fallback for every other country, a Vite dev proxy that keeps API keys server-side and serves `/registry/capabilities`, and optional React hooks (`useCompanySearch`, `useRegistryAvailability`).
